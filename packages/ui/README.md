# packages/ui

O design system (Documento 08, seção 88) por enquanto vive em `apps/web/src/components/ui` (componentes shadcn/ui), já que existe apenas uma aplicação frontend.

Este pacote será usado para extrair componentes compartilhados quando uma segunda superfície de frontend precisar deles — por exemplo, se o Control Center (Fase 20) nascer como aplicação separada em vez de rotas dentro de `apps/web`. Decisão a revisitar nessa fase.
